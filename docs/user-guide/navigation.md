# Navigate LabGoblin

LabGoblin presents only the sections available to your platform and
organization roles. Select the correct organization before working with labs or
VMs; changing organizations changes the tenant context sent with API requests.

On a compact screen, open the menu from the application header. Selecting a
destination closes the menu. Escape closes it without changing pages. On a
larger screen, the same destinations remain in the persistent sidebar.

## Main areas

- **Dashboard** summarizes the current organization's lab resources.
- **My Lab VMs** lists the machines you are authorized to use or manage.
- **Create VM** provisions from an effective classroom assignment.
- **Operations** shows durable work and its verified result.
- **Account Security** changes your password and manages sessions.

Instructors also receive the teaching workspace. Platform administrators
receive infrastructure and system administration sections. If a bookmarked URL
is no longer allowed, LabGoblin shows an access-denied page instead of the
restricted content.

Status messages distinguish success, work still in progress, warnings, and
failures. An empty view means the request succeeded but returned no records; an
error view means the request could not be completed.
